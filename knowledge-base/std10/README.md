# knowledge-base/std10

Place legally usable Gujarat Board (GSEB) Std. 10 study material here.

Supported formats: **PDF, TXT, MD, DOCX**

Import with:

```bash
cd backend
python -m scripts.import_documents --dir ../knowledge-base/std10 --standard 10 \
  --subject Science --chapter "પ્રકાશ – પરાવર્તન અને વક્રીભવન" --source-type curated
```

Or upload via Admin Panel → જ્ઞાન કોશ.

⚠️ Only ingest content you have the legal right to use (your own notes, licensed
material, or official content with permission). Sample/demo content shipped with
the app is clearly marked and must not be represented as official textbook text.
